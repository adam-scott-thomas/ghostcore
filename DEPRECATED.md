# ghostcore — DEPRECATED

**Date deprecated:** 2026-05-08
**Status:** Frozen public snapshot
**Successor:** [`ghostrouter`](https://pypi.org/project/ghostrouter/) (active development continues in a private repository)

## What happened

`ghostcore` and `ghostrouter` are the same project at different naming stages. The project was originally named `ghostcore`, then renamed to `ghostrouter` ("the LLM router that learns"). Active development moved to a separate repository when the project transitioned from open development to a paid-tier offering.

This repository contains the public history through **2026-04-17** (the "sync: local state 2026-04-17" commit). All work in this repo is also present in the canonical `ghostrouter` repository under different commit SHAs (the histories were committed independently).

## What this means for you

- **`pip install ghostrouter`** — the canonical PyPI package
- **No further releases will be made under the `ghostcore` name**
- This GitHub repo is being archived (read-only); the source is preserved here as a historical artifact
- For the latest source, use `pip install ghostrouter` and read the package contents
